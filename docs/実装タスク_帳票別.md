# 帳票別 実装タスク（エンジニア指示用）

対象は管理側 `a_filestatus/`。金額源は単一の「見積り送付」レコード（`DAT_FILESTATUS` ＋ 明細 `DAT_FILESTATUS_DETAIL`）。優先度: **P1=先に対応 / P2=次 / P3=任意・要判断**。

---

## 発注書（CB→サプライヤー｜preview_type=hcb）
- [ ] **P1｜サプライヤー原価（手数料抜き）を算出・組版する。** 現状は研究者面と同額を出し手数料表を隠すだけ。金額計算 `a_filestatus/index.php:1499-2214` は preview_type 分岐が無いので、hcb 用に「小計1（サービス費用）まで＝手数料・PF手数料・輸入/輸出代行・運営値引を含めない合計」を出す分岐を追加。`pdf_h.html` の hcb 側に素の金額の合計表を用意。
- [ ] **P1｜宛先ブロックを実装。** `pdf_h.html:2-13` の `[PDF_H_TO_CB]` はテストスタブ（"※出分けテスト用"）。Bill to＝サプライヤー等の実データに置換。
- [ ] **P2｜通貨をサプライヤー側にできるか検討。** 現状 `M2_CURRENCY`（`$FieldValue[21]`）単一を両面共用。別通貨要件があるなら項目追加。

## 発注書（研究者→CB｜preview_type=hr）

- [ ] **P1｜支払期限を取引ごとの値にする。** 現状 `[PDF_M3-M2_ETC03]`＝決裁者マスタ `DAT_M3.M2_ETC03` の静的値（`index.php:549-563`）。請求レコード側の値／請求時入力に変更。
- [ ] **P2｜サプライヤー側の S2_FILE 保存経路を正す。** `m_contact1` の請求保存INSERT（`:4159-4333`）に `S2_FILE` カラムが無く、実投入は管理側 FORM_S2 頼み。供給者画面で保存するか、管理側投入を正式運用と決める。
- [ ] **P2｜PREVIEW1/2 の出し分けを確定。** `index.php:685-706` が「どちらか不明で一旦両方表示」の仮実装。送信前=PREVIEW2、送信後=PREVIEW1 等に確定。
