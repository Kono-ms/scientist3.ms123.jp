# 各帳票が参照する見積データ（運営手数料の有無）

見積は同じ「見積り送付」レコードの2ビュー。
**見積書（CB宛）＝運営手数料なし（サプライヤーの素の金額）／ 見積書（研究者宛）＝運営手数料あり（研究者が払う総額）。**

原則：**サプライヤー側に立つ帳票は「CB宛見積（手数料なし）」、研究者側に立つ帳票は「研究者宛見積（手数料あり）」を参照する。**

| 帳票 | 参照する見積 | 運営手数料 |
|---|---|---|
| 見積書（CB宛・pdf_cb） | ― （それ自体） | **なし** |
| 見積書（研究者宛・pdf_r） | ― （それ自体） | **あり** |
| 発注書（CB→サプライヤー・hcb） | CB宛見積 | **なし** |
| 発注書（研究者→CB・hr） | 研究者宛見積 | **あり** |
| 請求書（研究者宛・pdf_s） | 研究者宛見積 | **あり** |
| 追加請求書（pdf_s_add） | 研究者宛見積 | **あり** |
| 請求書（サプライヤー→CB・添付） | CB宛見積 | **なし** |
| 納品書 | 金額を持たない | ― |

※現状の実装では、発注書（CB→サプライヤー・hcb）が手数料なしの金額を実際には出せていない（研究者宛と同額から手数料表を隠すだけ）。詳細と対応は [実装タスク_帳票別.md](実装タスク_帳票別.md) を参照。
