Scientist3 ／ 帳票発行フロー仕様メモ

発注書以降の書類は「どうあるべきか」と「現状どうなっているか」

研究者・コスモバイオ（運営）・サプライヤーの三者を仲介するモデルにおいて、サイトから発行される取引書類を発行者→宛先で棚卸ししたもの。 見積書（CB宛・研究者宛の2種）は既に把握済みの前提とし、その先の発注書・納品書・請求書に焦点を当てる。

  • 実装済 テンプレートも宛先も揃い、発行できる
  • 半完成 枠はあるが宛先・タイトル等が未整備／仮実装
  • 未実装 書類そのものが存在しない
  • 仕様どおり サイト発行せず添付（変更不要）

02

発注書 ── 2系統（hcb / hr）の意味

pdf_h.html / index.php:507-520

発注書は仲介モデルの2面に対応して2バージョン用意されている。分岐は hcb→[PDF_H_TO_CB]を表示、hr→[PDF_H_TO_R]を表示、というシンプルなもの。 現状 実装上の唯一の実差分は「hr版だけ手数料内訳表を出す／hcb版はそれを隠す」点で、宛先の描き分けはまだ入っていない。

hr
研究者面の発注書
研究者 ⇄ CB（手数料込みの総額）
あるべき
研究者がCBへ発注した内容の確定書。PF手数料・輸入/輸出代行・運営値引を含む合計金額を提示
現状
手数料内訳〜合計金額の表は表示される（pdf_h.html:104-188）が、上部の宛先は「R宛て（テスト用）」のダミー
管理画面
「発注書(研究者宛て発行用)」プルダウン
hcb
サプライヤー面の発注書
CB → サプライヤー（素の金額・手数料非表示）
あるべき
CBがサプライヤーへ発注する書類。CBの取り分（手数料）を伏せた素の金額のみ。送付で「受注承認」フローが起動
現状
手数料表を隠すだけで、中身は「CB宛て（テスト用）」のダミー。タイトルも住所も未整備
管理画面
「発注書(CB宛て / CB宛て閲覧用)」プルダウン
注意（宛先の向きは要確認）：管理画面のラベルは「CB宛て」「研究者宛て発行用」と紛らわしく命名されている。 コード上で確実なのは「hrは手数料込み＝研究者に見せる総額」「hcbは手数料抜き＝サプライヤー/CB間の素の金額」という金額の出し分けのみ。 「どちらを誰に送るか」の最終確定は業務側の意図に合わせて要レビュー。

あるべき姿

  • タイトルに PURCHASE ORDER / 発注書 を明示（現状 <h1> 欠落、見積のQuote No.流用）
  • hr / hcb それぞれに正しい Bill to / Ship to と発行者情報
  • 研究者面＝手数料込み、サプライヤー面＝素の金額、で金額を出し分け
  • プレビューの「送信」ボタンが発注書テンプレを指す

現状の実装

  • 宛先ブロックが「※出分けテスト用の記述部分です」のダミー（pdf_h.html:2-13）
  • タイトル <h1> なし。ヘッダは見積書のQuote No.を流用
  • 変数名の誤り：Bill to会社名が M2_SHIP_TO_SPT_2（Ship to名の名残）
  • disp_frame2の送信が preview_type=cb（見積CB）を誤指定して再ロード
03

納品書 ── 現状は存在しない

要・要否判断

あるべき姿（要検討）

  • 成果物/物品の納品時に、CB→研究者の納品書PDFを発行できると帳票が揃う
  • 「データ納品」「物品納品」の各ステータス遷移点で生成するのが自然
  • そもそも納品書を紙で出す運用が必要か、という業務判断が先

現状の実装

  • 納品書 / DELIVERY のテンプレート・モードは一切なし
  • 「納品」はステータス（納品確認 等）＋成果物ファイルの授受で代替
  • 明細行の「Deliverable:（納品物）」表記はあるが書類ではない
04

請求書 ── 添付は維持、研究者向けは組版が未整備

pdf_s.html / pdf_s_add.html

補足いただいたとおりサプライヤー→CBの請求書はサイト発行せず、サプライヤーが S2_FILE として添付する仕様で、ここは変更不要。 問題はその先、CB→研究者の請求書の作り方。

あるべき姿

  • CB→研究者の請求金額（サービス費用＋手数料＝見積の合計）を組版した請求書PDF
  • 案件名・請求番号・支払期限・振込先が揃った正式帳票
  • 追加請求も同じ様式で金額を明示

現状の実装

  • 金額を組版せず、アップロード済Invoiceファイルへのリンク付きカバーシート止まり
  • プレビュー分岐（送信前/後）が仮実装で、両方フル表示している
  • メール添付送信 sendPDF() は宛先・件名がハードコードのデバッグ状態＆呼び出しコメントアウト
整理：請求は「サプライヤーがInvoiceを添付 → CBが研究者向け請求レコード化 → pdf_s.html がそのファイルへのリンク付きカバーを生成」という流れ。 見積書・発注書と違いサイトが金額から組版する請求書PDFは存在しない（ファイル参照型）。
